# Preserved features — keep/remove review

5 November 2026 · 310 preview screens · 351 original modules preserved.

Sai approved preserving these unfinished features as explicit previews while deciding which to keep. No feature in this inventory was permanently removed. The previews do not load private records, save changes, charge users or send messages. Original code is retained byte-for-byte under `retained-previews/`; existing SQL plans remain in their original locations.

The active application is typechecked normally. Retained historical implementations are not wired into the app. Restoring one requires reviewed backend contracts, scoped permissions and tests; existing generated live types must not be fabricated to represent these drafts.

Descriptions are intended-use evidence from the original screen text or a labelled inference. They need business validation; they are not claims that the feature works. A suggested later phase is categorization only.

## Locally implemented areas awaiting hosted acceptance

The new account/RBAC, directory, community and commerce modules are separate from the retained historical modules. Their scoped models and local tests are preserved. Seven directory/community/commerce transports now use a no-network preview adapter until the corresponding backend is accepted. This does not undo the verified local SQL workflows or claim a live rollout. Phase 3 is 8/8 local and 0/8 hosted; Phase 4 ledger work is local and in progress. These core areas should be evaluated using the phase ledger, not confused with an unused historical screen.
